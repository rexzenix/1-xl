XL SATU LANDING PAGE V2

Fitur:
- Responsive HP/desktop
- Hero dari materi promo
- Paket FWA dan FTTH
- Tabel harga
- Form lead: nama, WhatsApp, area, layanan dan paket
- Form otomatis membuat pesan WhatsApp ke 0878 9930 7062
- Tidak membutuhkan database/server untuk fungsi form

PUBLISH GRATIS:
1. Buat akun GitHub.
2. Buat repository baru, misalnya xl-satu-landing.
3. Upload index.html dan promo-xl-satu.jpg.
4. Aktifkan GitHub Pages pada Settings > Pages > Deploy from branch > main > /root.
5. Website akan memperoleh alamat *.github.io.

Alternatif Cloudflare Pages:
- Buat project Pages baru.
- Upload/deploy kedua file ini sebagai static site.
- Akan memperoleh subdomain *.pages.dev.

PENTING:
Verifikasi harga, promo, cakupan area, logo/brand, ketentuan dan nomor kontak sebelum publikasi.
